# Project-Create 500 Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Perbaiki 500 `{"error":"internal error"}` saat create project sehingga `POST /api/workspaces/:slug/projects/` kembali 201.

**Architecture:** Satu baris query yang salah — `INSERT INTO project_identifiers` menyuplai `gen_random_uuid()` ke kolom `id` bertipe `bigint identity` (Django `ProjectIdentifier(AuditModel)` → BigAutoField, `apps/api/plane/db/models/project.py:264`). Error Postgres `column "id" is of type bigint but expression is of type uuid` membuat seluruh transaksi create rollback. Fix: hilangkan kolom `id` dari INSERT, biarkan identity DB yang generate. Read path (`check_identifier`, `project.rs:1366-1424`) sudah benar (`id: i64`) dan tidak disentuh.

**Tech Stack:** Rust (axum + sqlx), Postgres 5432 (docker `plane-for-itsm-plane-db-1`), Docker Compose service `api` (image `plane-api-rs:local`), cargo 1.96 host

- [ ] **Step 1: Reproduksi error di DB (bukti gagal dulu)**


Expected: `ERROR: column "id" is of type bigint but expression is of type uuid` (ROLLBACK membuat tidak ada data tersisa).

- [ ] **Step 2: Implementasi fix minimal**

Ubah `apps/api-rs/crates/api/src/routes/project.rs:603-617` dari:

```rust
    // `serializers/project.py:95`: the identifier registry row.
    let ident_res = sqlx::query(
        "INSERT INTO project_identifiers (id, name, project_id, workspace_id, created_by_id, updated_by_id, created_at, updated_at) \
         VALUES (gen_random_uuid(), $1, $2, $3, $4, $4, now(), now())",
    )
```

menjadi:

```rust
    // `serializers/project.py:95`: the identifier registry row. `id` is
    // `bigint generated by default as identity` (Django `ProjectIdentifier`
    // inherits the default BigAutoField — NOT a uuid), so it must be omitted
    // and left for the DB to generate; supplying `gen_random_uuid()` fails
    // with `column "id" is of type bigint but expression is of type uuid`
    // and rolls back the whole create transaction (500).
    let ident_res = sqlx::query(
        "INSERT INTO project_identifiers (name, project_id, workspace_id, created_by_id, updated_by_id, created_at, updated_at) \
         VALUES ($1, $2, $3, $4, $4, now(), now())",
    )
```

Binding `.bind(&ident).bind(project_id).bind(workspace_id).bind(creator)` tetap sama (4 binds, `$1..$4`), tidak diubah. Baris lain di blok ini tidak disentuh.

- [ ] **Step 3: Verifikasi query benar via SQL langsung**

Run:

```bash
docker exec plane-for-itsm-plane-db-1 psql -U plane -d plane -c "BEGIN; INSERT INTO project_identifiers (name, project_id, workspace_id, created_by_id, updated_by_id, created_at, updated_at) VALUES ('REPRO', gen_random_uuid(), '47567e0e-b42e-419a-bb71-a518722e10dc', '20a5770e-2030-410e-8034-6b65dc16fec6', '20a5770e-2030-410e-8034-6b65dc16fec6', now(), now()) RETURNING id, name; ROLLBACK;"
```

Expected: `INSERT 0 1` dengan `id` bigint ter-generate + `ROLLBACK` (tidak ada data tersisa).

- [ ] **Step 4: Commit**

```bash
git add apps/api-rs/crates/api/src/routes/project.rs
git commit -m "fix(api-rs): omit bigint identity id on project_identifiers insert"
```
