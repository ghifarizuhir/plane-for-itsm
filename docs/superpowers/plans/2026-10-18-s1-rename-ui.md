# S1 — Rename Project → Application (UI Copy, EN) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** User-facing copy says "Application(s)" instead of "Project(s)" everywhere in the main surfaces (sidebar, navigation, modals, settings, empty states, PowerK, toasts) — English locale only, zero schema/API change.

**Architecture:** EN locale JSON values are the source of truth, swept by a one-off script with a permanent regression guard (`check:copy`). Remaining hardcoded strings in components are edited by hand against a curated inventory, ending with a verification grep. 19 non-EN locales are explicitly out of scope here and ship as a separate plan (S1b).

**Tech Stack:** TypeScript, `tsx` scripts in `packages/i18n/scripts/` (mirrors `sync-check.ts`), oxfmt/oxlint, vitest (web), Rust/web untouched.

**Program context:** This is sub-project S1 of `docs/superpowers/specs/2026-10-18-project-to-application-design.md` (locked decisions: Application = renamed Project; config moves later in S2–S9; internal-first). Do not rename code identifiers, API paths, URL routes, DB tables, or i18n **keys** — values only.

---

## Scope / Non-goals

**In scope (S1):** EN i18n values (all 20 namespace files), hardcoded user-facing strings in `apps/web/core` + `apps/web/app`, three icon swaps, copy-guard script.

**Out of scope:**

- 19 non-EN locales → S1b (separate plan; `sync-check` will NOT flag stale values — keys stay identical on purpose).
- In-app guide `/docs` content and `apps/web/core/components/docs/**` (rewritten in S8).
- Integrations/importers data model; API/route/code identifier renames (S9 optional).
- `apps/web/core/store/**` dev logs, comments, test fixtures, component names.

**Never touch these values/strings (real-world "project" meanings):**

- `common.json` → `user_roles.product_or_project_manager` ("Product / Project Manager" — job title; also used as hardcoded default in `apps/web/core/components/settings/profile/content/pages/general/form.tsx:80`).
- `apps/web/core/components/onboarding/profile-setup.tsx:73` — `"Project"` is a job domain in `USER_DOMAIN`.
- `{project}`-style interpolation tokens (e.g. `integration.json` → `github_integration.issue_sync_message`: "Work items are synced to `{project}`") — token names are code contracts.

**Word map (apply with word boundaries, case-sensitive):**

| Match      | Replace with   |
| ---------- | -------------- |
| `Projects` | `Applications` |
| `Project`  | `Application`  |
| `projects` | `applications` |
| `project`  | `application`  |

Token rule: mask `/{[a-z][a-zA-Z0-9_.]*}/g` (lowercase-start interpolation tokens like `{count}`, `{project}`, `{max}`) before any word replacement/check, then restore. Do NOT mask ICU plural literals (`{count, plural, one {Project} other {Projects}}` — `workspace.json` → `workspace_projects.label`), those must be renamed in place.

**Baseline facts (2026-10-18 recon):** 323 EN values contain a project word; 1 allowlisted; 1 token-only; active deployment profiles use `en` only (6/6 profiles); `sync:check` has 19 pre-existing failures — capture the exact count before and after (must be identical).

**House rules:** stage exact paths only (never `git add -A`); lint-staged runs oxfmt+oxlint on commit; commit style `feat(i18n): …` / `feat(web): …` / `docs(spec): …`.

```ts
/**

// Usage:
//   tsx packages/i18n/scripts/copy-check.ts          # Report only
//   tsx packages/i18n/scripts/copy-check.ts --ci     # Exit 1 if violations found
//
// Fails when an en-locale VALUE still says project/projects (S1 rename guard).
// Interpolation tokens like {project}, {count} are ignored; ICU plural literals
// like {count, plural, one {Project} other {Projects}} are checked (and must be
// renamed in place).

import fs from "node:fs";
import path from "node:path";
// local imports
import { LOCALES_DIR, readJsonFile } from "./lib/locale-io.js";

// Key paths whose values legitimately contain "project" (real-world meanings).
const ALLOWLIST = new Set<string>(["common.json:user_roles.product_or_project_manager"]);

// Lowercase-start interpolation tokens only — ICU plural bodies stay visible.
const INTERPOLATION = /\{[a-z][a-zA-Z0-9_.]*\}/g;
const PROJECT_WORD = /\bprojects?\b/i;

function findViolations(): string[] {
  const dir = path.join(LOCALES_DIR, "en");
  const violations: string[] = [];

  for (const file of fs.readdirSync(dir).sort()) {
    if (!file.endsWith(".json")) continue;
    const json = readJsonFile(path.join(dir, file));

    const walk = (obj: Record<string, unknown>, prefix: string) => {
      for (const [key, value] of Object.entries(obj)) {
        const keyPath = prefix ? `${prefix}.${key}` : key;
        if (typeof value === "string") {
          if (ALLOWLIST.has(`${file}:${keyPath}`)) continue;
          if (PROJECT_WORD.test(value.replace(INTERPOLATION, "{token}"))) {
            violations.push(`${file}:${keyPath} :: ${value}`);
          }
        } else if (value && typeof value === "object") {
          walk(value as Record<string, unknown>, keyPath);
        }
      }
    };

    walk(json, "");
  }

  return violations;
}

const violations = findViolations();

if (violations.length === 0) {
  console.log("copy-check: clean — no project copy in en locale values");
  process.exit(0);
}

console.log(`copy-check: ${violations.length} en value(s) still say project:`);
for (const violation of violations) console.log(`  ${violation}`);

if (process.argv.includes("--ci")) process.exit(1);
```

```ts
/**
 * Copyright (c) 2023-present Plane Software, Inc. and contributors
 * SPDX-License-Identifier: AGPL-3.0-only
 * See the LICENSE file for details.
 */

// One-off S1 rename sweep: Project -> Application in EN locale VALUES only.
// Keys are never touched. Interpolation tokens ({project}, {count}) are
// preserved; ICU plural literals are renamed in place.
//
// Usage:
//   tsx packages/i18n/scripts/rename-project-copy.ts           # dry run
//   tsx packages/i18n/scripts/rename-project-copy.ts --apply   # write files

import fs from "node:fs";
import path from "node:path";
// local imports
import { LOCALES_DIR, readJsonFile } from "./lib/locale-io.js";

const ALLOWLIST = new Set<string>(["common.json:user_roles.product_or_project_manager"]);
const INTERPOLATION = /\{[a-z][a-zA-Z0-9_.]*\}/g;
const REPLACEMENTS: [RegExp, string][] = [
  [/\bProjects\b/g, "Applications"],
  [/\bProject\b/g, "Application"],
  [/\bprojects\b/g, "applications"],
  [/\bproject\b/g, "application"],
];

function renameValue(value: string): string {
  const tokens: string[] = [];
  let masked = value.replace(INTERPOLATION, (match) => {
    tokens.push(match);
    return `\u0000${tokens.length - 1}\u0000`;
  });
  for (const [pattern, replacement] of REPLACEMENTS) masked = masked.replace(pattern, replacement);
  return masked.replace(/\u0000(\d+)\u0000/g, (_, index) => tokens[Number(index)]);
}

const apply = process.argv.includes("--apply");
const dir = path.join(LOCALES_DIR, "en");
let changedValues = 0;

for (const file of fs.readdirSync(dir).sort()) {
  if (!file.endsWith(".json")) continue;
  const filePath = path.join(dir, file);
  const json = readJsonFile(filePath);
  let fileChanged = false;

  const walk = (obj: Record<string, unknown>, prefix: string) => {
    for (const [key, value] of Object.entries(obj)) {
      const keyPath = prefix ? `${prefix}.${key}` : key;
      if (typeof value === "string") {
        if (ALLOWLIST.has(`${file}:${keyPath}`)) continue;
        const renamed = renameValue(value);
        if (renamed !== value) {
          changedValues += 1;
          fileChanged = true;
          if (apply) obj[key] = renamed;
          else console.log(`${file}:${keyPath}\n  - ${value}\n  + ${renamed}`);
        }
      } else if (value && typeof value === "object") {
        walk(value as Record<string, unknown>, keyPath);
      }
    }
  };

  walk(json, "");
  if (apply && fileChanged) fs.writeFileSync(filePath, `${JSON.stringify(json, null, 2)}\n`);
}

console.log(`${apply ? "Applied" : "Would change"} ${changedValues} value(s) across en/*.json`);
```
