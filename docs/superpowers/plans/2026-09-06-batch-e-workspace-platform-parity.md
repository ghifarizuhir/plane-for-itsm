# Batch E Workspace/Platform Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement all remaining Django-backed endpoint groups (cycles, modules, pages, members/invites, favorites, workspace prefs/misc, user profile/activity, assets/attachments, advance-analytics, deploy-boards, auth sign-out, instance-admin/god-mode) with byte-exact Django parity, plus minimal FE-admin JWT adaptation.

**Architecture:** New-file-per-task (each task owns a disjoint file; no two tasks touch the same file): `routes/cycle.rs` (E2), `routes/module.rs` (E3), `routes/page.rs` (E4), `routes/member.rs` + `routes/invite.rs` (E5), `routes/favorite.rs` (E6), `routes/prefs.rs` (E7), `routes/user.rs` (E8), `routes/asset.rs` (E9), `routes/analytics.rs` (E10), append-only `auth.rs` (E11), `routes/instance_admin.rs` + `apps/admin` FE edits (E1, LAST); wire-up in `main.rs`; smoke in `scripts/smoke.sh`. Execution order: E2→E11 (FE-user surface first), E1 (god-mode) last, T12 final. `main.rs`/`smoke.sh` edits apply serially.

**Tech Stack:** Rust, Axum, SQLx (Postgres), `hmac`+`sha2` for SigV4 presigning (check `Cargo.toml`, add if absent — tiny), `reqwest` for the Unsplash proxy (check, add minimal features if absent), `lettre` for the SMTP credential check (check, add if absent). Celery/activity/webhook side-effects SKIPPED everywhere (Batch C/D precedent). Reuse Batch C/D helpers: `ws_role/project_role/deny()/missing()`, `FORBIDDEN_MSG`/`NOT_FOUND_MSG`, role ints 20/15/5, `issue_common.rs` paginator/envelope helpers (compare shapes first, reuse if identical).

## Locked contracts — Batch E additions (Django source, verified 2026-09-06)

1. **401 shape:** keep the locked generic `{"error":...}` (FE cares about status only) — intentional divergence from DRF's `{"detail":"Authentication credentials were not provided."}` on `/api/*`.
2. **403 shapes — replicate per endpoint, two variants exist:** `allow_permission` deny → 403 `{"error":"You don't have the required permissions."}` (`app/permissions/base.py:81-84`); DRF permission-class deny → 403 `{"detail":"You do not have permission to perform this action."}` (DRF framework default — applies to pages `ProjectPagePermission`, ws `project-members/` dict, project bulk/guarded branches noted below). Add an `AppError::forbidden_detail()` helper for the second shape; do NOT conflate.
3. **Django-500 rule (precedent D9):** where Django crashes (AttributeError/TypeError on missing rows, broken serializers), Rust returns the sane code — 404 `missing()` for missing-row crashes, 204 idempotent for missing-link deletes — and documents the deviation in the commit. NEVER replicate a 500.
4. **Broken-list rule:** Django routes whose viewsets lack a serializer (GET favorite collections, `GET user-favorite-modules/`) 500 in prod — Rust omits those routes (404 fallback). Exception watch: `GET user-favorite-projects/` IS FE-called (`project.service.ts:164`) — T12 must verify FE tolerance; fallback is a proper list implementation.
5. **201/200/204 audit:** statuses called out per row below wherever Django differs from 200. `PATCH` userprops cycle/module → **201**; favorites POSTs → **204** (empty); `user-favorites/` POST → **200** (object, or 200 existing on dup); deploy-board create (upsert) → **200**; workspace-views POST → **204**; page duplicate → **201**; asset presign POSTs → **200** triple.
6. **Invite JWT:** `jwt.encode({email,timestamp},SECRET_KEY,HS256)` — Rust verifies with the same `JWT_SECRET`, HS256, claims `{email,timestamp}`, NO expiry check (Django has none). Reuse existing JWT decode infra from `auth.rs`.
7. **GET `/api/users/me/` duplicate key:** Django `UserMeSerializer` emits `is_email_verified` TWICE (`serializers/user.py:63-87`) — Rust emits once (JSON-parse-equivalent; document deviation).
8. **Cache headers:** `GET /api/users/me/` and `GET /api/users/me/profile/` send `Cache-Control: private, max-age=12` + `Vary: Cookie` (`views/user/base.py:417-418`) — replicate headers.
9. **Pages `archived_at` format:** `str(datetime.now())` naive local with microseconds (`views/page/base.py:352`) — Rust: `chrono::Local::now().naive_local().format("%Y-%m-%d %H:%M:%S%.6f")` (container TZ == Django TZ, both system local).
10. **Pages description streaming:** `StreamingHttpResponse` single-`yield` of raw `description_binary` bytes (`base.py:526-533`) == plain Axum body bytes with `Content-Type: application/octet-stream` + `Content-Disposition: attachment; filename="page_description.bin"` — observably identical, no chunking games.
11. **Notification prefs GET:** Django 404s when the row is missing (backfill was migration-only) — Rust does get-or-create (200 always). Intentional deviation: superset of Django (identical whenever the row exists), keeps the FE email form alive.
12. **PUT `modules/<pk>/`:** Django has NO permission decorator (auth-only) — Rust enforces `[ADMIN,MEMBER]` like PATCH. Intentional hardening; the legit FE caller (`apps/web` `updateModule`) always has a role.
13. **Project-invite create bugs:** Django has three (`.filter().role` AttributeError, error return without `status=`, celery `.delay` on a list) — Rust implements the INTENDED behavior (400 validations + `200 {"message":"Email sent successfully"}` + email SKIP). Document; FE never calls these routes.
14. **MinIO presign host rule (critical):** `USE_MINIO==1` → presigned host = the incoming request's `Host` (scheme from `MINIO_ENDPOINT_SSL` or request scheme), NOT `plane-minio:9000` (`settings/storage.py:46-53` + proxy `/{BUCKET}/*` → minio). Non-MinIO (real S3) → configured endpoint. Env names: `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` / `AWS_S3_BUCKET_NAME` (NOT `AWS_STORAGE_BUCKET_NAME`) / `AWS_REGION` / `AWS_S3_ENDPOINT_URL` or `MINIO_ENDPOINT_URL` / `USE_MINIO` / `MINIO_ENDPOINT_SSL` / `SIGNED_URL_EXPIRATION` (3600 both directions) / `FILE_SIZE_LIMIT` (clamp via `min(client, limit)`, never reject).
15. **Asset GET split:** app-scope GETs (`v2/.../<id>/`, downloads) → **302** to presigned GET (disposition `attachment`, except `static/` which is `inline`, `attachment` only for script-MIMEs); public-generic `GET .../assets/<id>/` → **200 JSON** `{asset_id,asset_url(presigned),asset_name,asset_type}` — preserve the split byte-exactly.
16. **Scope cut:** `plane/api/*` (public v1) and `plane/space/*` (anchor) asset/invite/cycle routes are OUT (versioned/public API, no FE callers — E5/E9 precedent). `plane/app/*` only.
17. **Email sends everywhere (invites, verification codes):** rows + tokens created, celery `.delay` SKIPPED, success messages preserved.
